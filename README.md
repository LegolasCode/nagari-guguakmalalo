# Website Nagari Guguak Malalo

Website Resmi Nagari Guguak Malalo adalah sebuah platform digital layanan publik terintegrasi yang dikembangkan untuk mendukung transparansi dan efisiensi birokrasi di Nagari Guguak Malalo, Kabupaten Tanah Datar, Sumatera Barat. 

Sistem ini berfungsi sebagai jembatan interaksi digital antara pemerintah nagari dan masyarakat, mulai dari penyajian profil wilayah, pemetaan potensi lokal (pertanian, UMKM, dan pariwisata), hingga digitalisasi administrasi layanan dokumen mandiri.

---

## ✨ Fitur Utama

Aplikasi ini menerapkan **Role-Based Access Control (RBAC)** yang memisahkan hak akses antara pengelola (Admin) dan warga (Public/User):

### 1. Portal Publik (User Interface)
* **Profil & Statistik Nagari:** Visualisasi data demografi penduduk, profil nagari, serta potensi sektor pertanian.
* **Promosi Lokal:** Wadah digital untuk memperkenalkan produk UMKM dan destinasi pariwisata unggulan setempat.
* **Layanan Dokumen Online:** Pengajuan surat-surat official dan dokumen administratif secara mandiri tanpa harus mengantri lama di kantor nagari.
* **Sistem Pengaduan Masyarakat:** Media interaktif bagi warga untuk menyampaikan keluhan, aspirasi, atau laporan langsung kepada jajaran pemerintah desa.

### 2. Dashboard Manajemen (Admin Panel)
* **Content Management System (CMS):** Pengelolaan artikel berita, info pariwisata, profil desa, dan katalog UMKM.
* **Verifikasi Dokumen:** Manajemen dan pemrosesan permohonan surat masuk dari masyarakat secara digital.
* **Manajemen Konten Publik:** Memperbarui data informasi layanan masyarakat secara real-time.

---

## 🛠️ Teknologi & Stack yang Digunakan

* **Backend Framework:** Laravel (PHP)
* **Frontend Interface:** Bootstrap, HTML5, CSS, JavaScript
* **Database Management:** MySQL
